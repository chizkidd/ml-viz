How well does the simulator match? (calibration check)
The simulator has four fitted constants (decode step time and prefill cost). Fitted on these runs, so this checks the fit, not an independent prediction. The ratio between the policies is the part to trust. Absolute levels drift at large batch sizes, where the real engine slows down more than the model does.

Contiguous slots vs paged blocks simulated snapshot

One memory pool, the same requests. Contiguous reserves a full max-length slot per request. Paged hands out small blocks sized to what each request needs. Each row below is 732 tokens wide, the engine's slot size.

Block size trade-off measured

Bigger blocks mean fewer table lookups but more rounding waste. Goodput barely moved, rounding waste exploded.

How fast can decode possibly go? published specs + formula

Each decode step reads every weight once plus every sequence's KV cache. Memory bandwidth sets the speed limit, memory capacity sets how many sequences fit.
