Muon & MuonClip: Matrix-Aware Optimizers

Adam treats a neural network as one flat vector, so 2D weight updates collapse onto a handful of dominant singular directions. Muon orthogonalizes the momentum matrix with five quintic Newton-Schulz iterations so rare directions get equal step size, and MuonClip caps runaway per-head attention logits without disturbing healthy heads. Every matrix, singular value, trajectory, and logit curve below is computed live in pure JavaScript.

Start with a rank-skewed 4×4 momentum matrix G = U S VT, normalize by its Frobenius norm (X0 = G / (||G||F + 10−7)), and iterate the odd quintic polynomial Xk+1 = aXk + b(XkXkT)Xk + c(XkXkT)2Xk. Because odd polynomials preserve U and V, every iteration acts purely on each singular value σi → p(σi).

Update matrix singular-value spectrum (normalized σ1, σ2 of ΔW)

Muon's Newton-Schulz orthogonalization makes the update step nearly isotropic (σ2 / σ1 → 1), pushing equally along weak and strong directions. Coordinate-wise AdamW stays skewed whenever curvature is rotated off the coordinate axes.
Under Muon updates, aligned query/key heads can grow their attention logits Smaxh = maxi,j (qih · kjh) / √d quadratically, collapsing softmax into a one-hot spike. MuonClip (QK-Clip) monitors each head independently and rescales Wqh ← √γh Wqh, Wkh ← √γh Wkh with γh = min(1, τ / Smaxh) — leaving healthy heads completely untouched.
